# 🚀 Space Game

A 2D Space Shooter game built with Python and Pygame.

## Features
- Space shooter gameplay
- Built with Python and Pygame

## Installation
```bash
git clone https://github.com/jolimarzia/space-game.git
cd space-game
```

## Install Dependencies
```bash
python -m pip install -r requirements.txt
```

## Run the Game
```bash
python main.py
```
